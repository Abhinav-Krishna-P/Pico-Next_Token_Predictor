How to read this

  • Exact match is strict: a valid correction that is worded differently from the key (e.g. a different but correct tense) counts as a miss, so the real usefulness is higher than this number.
  • Edit F0.5 compares the word changes Pico made with the changes in the key, weighting precision twice as much as recall (the usual grammar-correction metric: a wrong change is worse than a missed one).
  • The test set is small (30 sentences), so each sentence is worth 3.3 percentage points.
  • 10 sentence(s) were left unchanged or not improved. These are mostly harder rules (e.g. He go to school by bus every day., My brother is more taller than me., He have been working since morning.): adding examples of these patterns to the synthetic training data is the next step.
